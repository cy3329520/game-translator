# 游戏实时翻译器（macOS / Windows）

框选游戏画面上的一块区域，程序持续盯着它：**画面一变就自动截图 → 交给 DeepSeek 视觉模型
一次完成 OCR + 日译中 → 把中文字幕贴在框选区域的正下方**。

用的模型是 `deepseek-flash`，走 Responses API，截图以 `input_image` 内容块直接传给模型，
所以**不需要在本机安装任何 OCR 引擎**（不用 PaddleOCR / manga-ocr / torch）。

---

## 一、快速开始

最省事的方式：在访达里双击 **`start.command`**（macOS 会用「终端」打开并启动）。

Windows：在资源管理器里双击 **`start.bat`**。

或者用命令行（macOS / Linux）：

```bash
cd ~/game-translator
./run.sh
```

首次运行会自动建虚拟环境并装依赖（`mss` / `Pillow` / `requests` / `pynput`），之后直接启动。
依赖已经装好了，直接启动即可。

启动后三步走：

1. **填 API Key**：在「翻译」页粘贴你的 DeepSeek API Key（到
   <https://platform.deepseek.com> 的「API Keys」里创建），点「测试接口连通性」确认可用。
2. **框选区域**：点「框选区域」→ 屏幕会变暗 → 拖动鼠标框住游戏里的日文对话/字幕 → 点「✓ 使用此区域」。
   框完会自动弹一个预览窗，让你确认抓到的画面是对的。
3. **选模式并开始**：选「自动」或「手动」，再点「▶ 开始实时翻译」。

   - **自动**：画面一变就自动翻译，不用管
   - **手动**：区域旁边会出现一个悬浮的「翻译」按钮，点一下才翻一次

   两种模式下都可以随时按 **⌘ ⇧ T** 手动补翻一次。

## 二、系统权限（第一次必须做）

### Windows
Windows 不需要额外授权。如果截图预览是黑屏/纯色，通常是安全软件或显卡驱动拦截了屏幕捕获，
或游戏运行在**独占全屏**模式，请把游戏改成「无边框窗口」。

### macOS

| 权限 | 用途 | 设置路径 |
|---|---|---|
| **屏幕录制** | 截取游戏画面。**没授权的话截到的只会是桌面壁纸** | 系统设置 → 隐私与安全性 → 屏幕录制 → 勾选你启动程序的终端（Terminal / iTerm） |
| **辅助功能** | 全局快捷键 ⌘⇧T。不授权只影响快捷键，其余功能正常 | 系统设置 → 隐私与安全性 → 辅助功能 → 勾选终端 |

授权后**需要重启程序**（有时还要重启终端）才生效。

授权的正确姿势是按你实际启动程序的那个 App 来勾选，比如双击 `run.sh` 时要给 Terminal 授权。

### 先跑自检

不确定权限给对没有，可以先跑：

```bash
.venv/bin/python selfcheck.py
```

它会在屏幕中央闪一个红方块，然后验证：能不能真的抓到屏幕内容、Retina 缩放换算对不对、
变化检测灵不灵、图片编码正不正常。**如果提示"未捕获到红块"，就是屏幕录制权限没给。**

## 三、界面说明

### 翻译页
- **API Key**：本地保存在 `~/.game-translator/config.json`，不会上传到任何地方。
- **接口地址**：默认 `https://api.deepseek.com`，一般不用改；只有走代理或自建网关时才动它。
- **测试接口连通性**：发一个极小的纯文本请求验证 Key / 网络 / 接口，不消耗图片 token。
- **框选区域 / 预览截图 / 隐藏字幕**：预览截图建议每次换游戏场景后点一下，确认区域没框歪。
- **测试字幕置顶**：显示一条测试字幕并报告当前层级，用来确认字幕能盖在游戏画面之上。
- **自动翻译**：勾上=画面变化自动触发；不勾=只响应快捷键和「立即翻译一次」。
- **立即翻译一次**：引擎没启动时会自动帮你启动。

### 设置页
| 参数 | 默认 | 说明 |
|---|---|---|
| 思考模式 | 关闭（最快） | 关掉思考能让首字延迟明显降低；翻译任务基本不需要思考 |
| 输出格式 | 仅译文 | 可切「日文 + 译文」，同时看到原文 |
| 图片精度 | high | 保留原图，识别更准；`low` 会先缩到 512×512，更省但小字容易糊 |
| 最大输出 tokens | 1024 | 被截断时日志里会提示 |
| 截图最长边 | 1280 | 送模型前缩放的上限，越大越准也越贵 |
| 检测间隔 | 200ms | 多久截一次图做比对（纯本地操作，不花钱） |
| 稳定判定 | 350ms | 画面静止多久才发翻译请求，用来等打字机效果把话显示完；0 = 最快 |
| 请求最小间隔 | 1200ms | **控费用的关键**：两次请求至少隔这么久 |
| 变化灵敏度阈值 | 0.10 | 单位是「明显变化的像素占比 %」，越小越敏感。画面有循环动画时调大 |
| 字号 / 不透明度 / 间距 | 16 / 0.92 / 8 | 字幕条外观 |
| 置顶层级 | 最高 · 盖住所有应用 | 字幕盖在哪些窗口之上，详见下方「字幕置顶」一节 |
| 组合键 | `<cmd>+<shift>+t` | 语法如 `<cmd>+<shift>+t`、`<ctrl>+<alt>+j`，改完点「注册」 |
| 追加提示词 | 空 | 写给模型的额外要求，例如「把『お姉さん』统一译成『大姐姐』」「保留技能名原文」 |

### 日志页
每条记录含：耗时 · 首字延迟 · token 用量 · 译文。排查问题先看这里。

### 两种模式

| | 自动模式 | 手动模式 |
|---|---|---|
| 触发方式 | 画面一变就翻 | 只有点悬浮按钮 / 按快捷键才翻 |
| 悬浮按钮 | 不显示 | 显示在**翻译区域右侧**，点一下翻一次 |
| 适合 | 剧情对话、字幕密集 | 想省额度、只在看不懂时点一下 |

切换方式：「翻译」页 →「模式」单选，切完立即生效，不用重启。

**悬浮按钮的几个细节：**

- 贴在框选区域的**右侧**、与区域顶部对齐；右边放不下会自动挪到左侧
- 按钮**不会激活本应用**（用了 Tk 的 `noActivates` 窗口样式），
  点它**不会让游戏失焦暂停**
- 翻译期间按钮变成「翻译中…」并暂时禁用，拿到结果后自动恢复
- 和字幕条一样是原生最高层级，不会被游戏窗口压住
- 只有在**引擎运行中**且**已框选区域**时才显示

> 如果游戏对失焦特别敏感（一失焦就暂停），可以用 **⌘⇧T** 快捷键代替点按钮 ——
> 快捷键完全不碰窗口，不会有任何焦点变化。

### 翻译什么时候触发？（重要）

**不是一直请求 API。** 完整流程：

1. **每 200ms 截一次图**（纯本地操作，不花钱），把画面缩成灰度小图
2. 和上一帧比对：**有明显变化的像素占比 ≥ 0.1%** 才算「画面变了」
3. 画面一变**不马上发请求**，而是记下来等它安静下来：
   - 连续 3 次检测（约 600ms）都没有新变化，**并且**
   - 距最后一次变化 ≥「稳定判定」时间

   两条都满足才真正发请求
4. 这样游戏用**打字机效果逐字显示**对话时，**一句对话只翻一次**，
   而不是每冒出几个字就翻一遍、翻到半句话
5. 请求走**流式**传输，第一个字回来就上屏，不用等整句翻完

另外两道保险：

- **请求最小间隔**：两次请求之间至少隔这么久，防止画面抖动导致刷屏
- **最长等待**：画面上有循环动画（立绘、特效）时永远等不到"静止"，
  所以最多等 2.5 秒也会强制翻一次

手动触发（快捷键 / 「立即翻译一次」）会**跳过等待**，立刻发请求。

实测（24 字对话）：

| 文字出现方式 | 发出的请求次数 |
|---|---|
| 瞬间整段出现 | 1 次 |
| 打字机 60ms/字（常见） | 1 次 |
| 打字机 180ms/字（很慢） | 2 次（先翻半句，再更新为完整句） |
| 逐行出现 400ms/行 | 每行各 1 次 |

### 字幕置顶（重要）

字幕要盖在游戏画面上。但 macOS 上 Tk 自带的 `-topmost` 只是把窗口标成"浮动"，
**原生窗口层级仍然是 0**，遇到全屏或无边框游戏照样会被压住。

所以程序在 macOS 上会直接用 AppKit 把字幕窗层级拉到 **NSScreenSaverWindowLevel (1000)**，
并额外设置三项：

- **跟随所有 Space**（`CanJoinAllSpaces` + `FullScreenAuxiliary`）—— 让字幕能出现在全屏应用所在的 Space
- **鼠标穿透**（`ignoresMouseEvents`）—— 字幕条不拦截点击，即使盖住画面也不影响游戏操作
- **失活不隐藏**（`hidesOnDeactivate = false`）—— 焦点切到游戏后字幕条依然显示

「置顶层级」四档可选：

| 档位 | 原生 level | 效果 |
|---|---|---|
| 最高（默认） | 1000 | 盖住所有应用，含全屏游戏 |
| 较高 | 25 | 盖住应用与菜单栏 |
| 普通 | 3 | 只浮在普通窗口之上 |
| 关闭 | 0 | 用系统默认层级 |

改完立即生效，不用重启。点「测试字幕置顶」可以马上验证是否生效。

## 四、调参建议

**嫌慢？**
- 思考模式选「关闭」
- 「稳定判定」调到 0~150ms（画面一变就翻，代价是打字机效果可能先翻半句）
- 「请求最小间隔」降到 600~800ms
- 「截图最长边」降到 900
- 图片精度改 `low`（但小字会糊）

**嫌费钱？**
- 切到「**手动模式**」：只有你点悬浮按钮时才发请求，额度完全可控
- 「稳定判定」调到 500~800ms（等整句话显示完再翻，减少请求次数）
- 「请求最小间隔」调到 2500ms 以上
- 「变化灵敏度阈值」调大，减少无效触发
- 「截图最长边」降到 800

**字幕老是重复翻译同一句？**
调大「稳定判定」和「变化灵敏度阈值」；或者干脆关掉自动模式，改用手动快捷键。

**游戏有立绘动画导致疯狂触发？**
调大「变化灵敏度阈值」（比如 1.0~2.0）。因为有「最长等待 2.5 秒」兜底，
即使永久检测到变化，也只会 2.5 秒翻一次，不会失控。

## 五、已知限制

- **推荐游戏用「窗口化 / 无边框窗口」运行**。程序已用原生 API 把字幕拉到最高层级并跟随全屏
  Space，多数情况下能盖在游戏上；但少数使用**独占全屏**的游戏，系统层面就不允许别的窗口覆盖，
  必须在游戏自己的画质设置里改成「无边框窗口模式」。
- 目前固定**日文 → 简体中文**。要改别的语言，编辑 `src/config.py` 里的提示词常量即可。
- 只抓**主显示器**。
- **Windows 上字幕条为完全不透明**（鼠标穿透依赖分层窗口，半透明与穿透不可兼得）；
  macOS 上「不透明度」设置正常生效。
- 自动模式下每次触发都是一次独立 API 请求（Responses API 是无状态的，不保留上下文）。
  翻译的是"当前这一帧"，不做对话连贯性追踪。

## 六、文件结构

```
game-translator/
├── start.command       双击启动（macOS 用「终端」打开并运行）
├── run.sh              一键启动（自动建 venv + 装依赖）
├── app.py              程序入口
├── selfcheck.py        无 GUI 自检脚本
├── requirements.txt
├── README.md
└── src/
    ├── config.py         配置读写 + 翻译提示词
    ├── deepseek.py       Responses API 客户端（流式 SSE，一次完成 OCR + 翻译）
    ├── capture.py        截屏、Retina 换算、区域框选、变化检测
    ├── overlay.py        置顶悬浮字幕条 + 手动模式的悬浮按钮
    ├── platform_window.py 原生窗口层级控制（macOS 用 AppKit，Windows 用扩展窗口样式）
    ├── engine.py         后台工作线程：截图 → 检测 → 请求 → 投递结果
    ├── hotkey.py         全局快捷键
    └── ui.py             主控制台界面
```

配置文件：`~/.game-translator/config.json`（删掉它即可恢复默认设置）

## 七、常见问题

**Q：报「无法连接 http://127.0.0.1:xxxx」或 Connection refused？**
「接口地址」被改成了本地地址。到「翻译」页把「接口地址」改回 `https://api.deepseek.com` 即可。

**Q：报「无法连接 …：连接被拒绝 / 域名解析失败 / 连接超时」？**
请求发不出去。依次检查：接口地址是否写对、网络是否通、是否需要走代理。

**Q：截图预览是全黑 / 桌面壁纸？**
屏幕录制权限没给。去系统设置授权后重启程序。

**Q：快捷键按了没反应？**
辅助功能权限没给。或者组合键被别的软件占了，换一个（如 `<ctrl>+<alt>+j`）。

**Q：字幕被游戏盖住了 / 根本看不见？**
1. 点「测试字幕置顶」，看日志里是不是提示"已置于原生层级"
2. 到设置页确认「置顶层级」是「最高 · 盖住所有应用」
3. 把游戏的显示模式改成「窗口化」或「无边框窗口」
4. 如果游戏用的是**独占全屏**（exclusive fullscreen，画质设置里常见），系统层面禁止任何窗口
   覆盖它，只能改成无边框窗口模式

**Q：字幕条挡住游戏了，点不到下面的按钮？**
不会。字幕条已开启**鼠标穿透**，点击会直接落到游戏上。它只是"看得见、点不着"。

**Q：字幕条盖住了游戏文字？**
说明框选区域太靠屏幕底部了，程序会自动把字幕翻到区域上方。也可以调大「字幕与区域间距」，
或者把「不透明度」调低一点。

**Q：报 `API Key 无效或未授权`？**
检查 Key 是否复制完整、有没有多余空格；确认账号有余额。

**Q：报 `请求过于频繁，已被限速`？**
把「请求最小间隔」调大。

**Q：想换回默认设置？**
删掉 `~/.game-translator/config.json`，重启程序。

**Q：启动时报缺 tkinter？**
如果用 Homebrew 的 Python：`brew install python-tk`。
